# Требования к утилите

## 1. Назначение
Утилита предназначена для разворачивания окружения разработчика на основе входных config-файлов.

## 2. Пользовательский сценарий
Пользователь может развернуть окружение с помощью скрипта devshell.ps1 передав массив имен заранее подготовленных конфигураций
devshell.ps1 <config_files>

## 3. Входные данные
Обязательные параметры:
config_files - массив имен конфигураций

## 4. Выходные данные
В соответствии с переданным массивом имен конфигураций создаются, обновляются или удаляются определенные переменные окружения

## 5. Основные функции
Утилита должна:
- искать конфигурационные файлы в соотвествии с файлами настроек пользователя
- применять команды из конфигурационных файлов, переданных в качестве аргумента

## 6. Обработка ошибок
Ошибочные ситуации:
- не найден переданный конфигурационный файл - скрипт уведомляет пользователя об ошибке, но продолжает работу
- не найден файл настроек пользователя - скрипт уведомляет пользователя о критичной ошибке, завершает работу

## 7. Интерфейс
Способ использования: CLI (интерфейс командной строки)
